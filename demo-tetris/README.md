# Desktop Tetris

Run `./run.sh`; test with `./test.sh`. A/D move, W rotates, Space drops, P pauses, R restarts, Q exits. Requires a C compiler, Python 3 and a terminal at least 45×29. This adapter uses the pinned upstream pure C model, not an ESP32 emulator. Tests include sanitizers, one million random actions and PTY interaction.
