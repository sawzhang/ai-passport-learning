## 真机发现的问题与修复

首版在构建 UI 后只剩 2048 字节内存，按键任务创建失败并重启。第二版能进入待配对状态，但 I2S RX DMA 分配失败。最终版采取紧凑 UI、8 行单显示缓冲、关闭可选 8KB 头像脏区缓存、减小无线缓冲、80ms 音频预录、I2S 每方向 3×120 帧 DMA。最终 UI 构建后剩 40412 字节，音频就绪时剩 12984 字节；Wi-Fi 扫描结束后心跳约 25–26KB，最大空闲块约 7–8KB。

这些数字来自尚未配对的运行阶段。**TLS/云端会话和录音上传的峰值内存仍待测**，不能据此承诺联网稳定性。

## 配对后继续验收

1. Muse app Developer mode 中选择广播的 MuseGadget，设备 OK 确认，经 app 配置 2.4GHz Wi-Fi。记录配对确认、获得地址和云端 session 建立证据，不公开凭据或设备标识。

3. 三键逐项检查，菜单上下、OK 选择、DOWN 长按返回，反复进出 10 次；观察屏幕旋转、色彩、裁切和配对提示可读性。
4. 联网运行至少 10 分钟，统计重启、异常、最小/最大空闲堆；断开并恢复网络，确认重连；关机开机确认配对和设置持久化。
5. 独立验收扬声器声音、音量、麦克风实际语音。无 PSRAM 配置的 Muse 回答为文字，不能把“没有语音回答”当作已经实现 TTS。

新固件已编译、通过镜像验证并刷入，四个写入段均通过哈希校验。应用 SHA-256：`52fef5412c720b4a8276865690831493b3c993a8536d5d9644e37415e175f80d`。设备刷入后正常运行并广播，当时待手机复测；后续成功状态见下文。
